# Enterprise Hospital Management System Backend

Modules Included:
- Authentication
- Patient Management
- Doctor Management
- Appointment Management
- Prescription Module
- Billing Module
- Pharmacy Module
- Laboratory Module
- Dashboard Foundation
- Swagger Configuration

## Run

1. Create database:

CREATE DATABASE hms_db;

2. Update application.properties

3. Run:

mvn spring-boot:run

## Swagger

http://localhost:8080/swagger-ui/index.html
